# Text-to-Speech Translator

A simple Streamlit application that translates text into a selected language and converts it into speech.

### Features
- Text translation
- Multiple language selection
- Text-to-speech conversion
- Audio playback

### Technologies
- Python
- Streamlit
- gTTS
- deep-translator

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
